# GRC Risk Assessment — Northstar Medical Group

## Overview
Conducted a risk assessment of the Northstar Medical Group Active Directory and EHR environment, aligned to NIST CSF 2.0 and HIPAA Security Rule.

## Deliverables
- Risk Register (15 risks identified, 4 rated High)
- NIST CSF Gap Analysis (across 5 functions)
- Access Control Policy (draft)
- Executive Summary

## Frameworks & Standards Used
- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-53 (control references)
- HIPAA Security Rule
- CIS Controls v8

## Skills Demonstrated
Risk assessment · Control gap analysis · Policy development · Executive reporting · NIST CSF · HIPAA compliance

## Key Findings
| Risk | Score | Recommended Control |
|---|---|---|
| Over-provisioned EHR access | 15 | Quarterly access reviews |
| Delayed offboarding | 12 | Automated IAM workflow |
| No MFA on admin accounts | 20 | Enforce MFA + PAW |
